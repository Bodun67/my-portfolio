# My Portfolio

Невеликий сайт-візитка Романіва Богдана — студента IT-напряму та системного адміністратора-початківця.

## Технології

- HTML
- CSS
- JavaScript

## Запуск

1. Відкрийте файл `index.html` у браузері.
2. Або відкрийте папку проєкту в Cursor і запустіть Live Server, якщо він встановлений.

## Функціональність

Сайт містить коротку інформацію, контакти та блок «Мої навички». У гілці `feature/theme-toggle` додано перемикач світлої й темної теми.

## Безпека

Файл `.env` призначений лише для локальних демонстраційних змінних. Він доданий до `.gitignore`, тому не потрапляє в Git-історію та на GitHub. Папка `node_modules` також ігнорується.
